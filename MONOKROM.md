# 👕 MONOKROM

**MONOKROM** adalah website e-commerce toko baju yang dirancang untuk membantu customer melihat produk, memilih produk sesuai ukuran dan warna, mengelola keranjang, melakukan checkout, serta melihat dan melacak status pesanan.

Website ini juga menyediakan halaman admin untuk mengelola produk, stok, dan pesanan customer.

Project ini dikembangkan sebagai bagian dari tugas mata kuliah **Pemrograman Web Dasar (PWD)** menggunakan HTML, CSS, JavaScript, dan jQuery.

## ✨ Fitur Utama

### 👤 Customer

- **Katalog Produk** — Menampilkan daftar produk baju yang tersedia.
- **Pencarian Produk** — Membantu customer mencari produk berdasarkan nama.
- **Detail Produk** — Menampilkan foto, nama, harga, ukuran, warna, dan informasi stok produk.
- **Keranjang Belanja** — Customer dapat menambahkan produk, mengubah jumlah, dan menghapus produk dari keranjang.
- **Checkout Pesanan** — Customer dapat mengisi nama, nomor HP, alamat pengiriman, dan metode pembayaran.
- **Nomor Pesanan** — Customer mendapatkan nomor pesanan setelah checkout berhasil.
- **Lacak Pesanan** — Customer dapat melihat status pesanan menggunakan nomor pesanan.
- **Status Pesanan** — Menampilkan status pesanan seperti Diproses, Dikirim, dan Selesai.

### 🛠️ Admin

- **Manajemen Produk** — Admin dapat melihat, menambah, mengedit, dan menghapus produk.
- **Manajemen Stok** — Admin dapat memperbarui jumlah stok produk.
- **Manajemen Pesanan** — Admin dapat melihat daftar dan detail pesanan customer.
- **Update Status Pesanan** — Admin dapat memperbarui status pesanan sesuai proses pemesanan.
- **Informasi Pengiriman** — Admin dapat menentukan kurir dan memasukkan nomor resi pengiriman.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML5 | Membuat struktur halaman website |
| CSS3 | Mengatur tampilan, desain, dan tata letak website |
| JavaScript | Menambahkan logika dan interaktivitas website |
| jQuery | Mempermudah manipulasi DOM dan penanganan event |
